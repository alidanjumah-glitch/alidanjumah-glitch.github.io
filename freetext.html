Sentiment Method

Sentiment is an auditable estimate based on a transparent bilingual-ready lexicon architecture (currently English), contextual negation handling and term weighting. A score is retained for every response. Automated sentiment should be human-reviewed for publication-critical work.

Automated Thematic Analysis

Themes are evidence-driven from domain concept dictionaries, n-grams, term co-occurrence and TF-IDF-style relevance. Theme assignments retain evidence and confidence; low-confidence classifications can be filtered or reviewed.

Methodology & Traceability

Pipeline: ingestion → preserve original text → cleaning → stop-word control → term/response frequency → n-grams → sentiment → evidence-based theme matching → confidence/relevance → audit relationships → human review → report.

Question-aware audit principle: every primary theme classification stores the question/column header, Response ID, original response, extracted terms/phrases, theme, relevance score, evidence and sentiment. The question header is contextual only; it cannot by itself create a theme assignment.

Privacy: this file processes uploaded data in the browser. It does not intentionally send survey responses to a server. External CDN libraries are loaded by the browser when internet access is available.
